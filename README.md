# Hausaufgabe 1

Das FastAPI-Backend stellt die API-Endpunkte /api/ping und /api/pong bereit. Über das Frontend können Nutzer per Button "Ping" die aktuelle Serverzeit abrufen oder per Button "Pong" ein „Pong“-Signal senden.




## Authors

- [DenisGelgorn](https://github.com/DenisUni)
- [Martin Küchler](https://github.com/martinkuechler)




## Installation

Install my-project with npm


  #### 1. Repository klonen:
  ```bash
git clone https://github.com/martinkuechler/einfuehrungsblatt.git
cd einfuehrungsblatt
```

#### 2. Umgebung einrichten:
```bash
python -m venv venv
source venv/bin/activate # Windows: venv\Scripts\activate
pip install -r requirements.txt
```

#### 3. Server starten:
```bash
uvicorn api:app --reload
```
Der Server läuft standardmäßig auf: http://127.0.0.1:8000
